# PhishGuard – Phishing Awareness Website 🛡️

## About the Project

PhishGuard is a simple website created to spread awareness about phishing attacks.

This website helps users understand phishing, identify warning signs, and learn some basic safety tips to stay safe online.

## Features

* Learn about phishing
* Phishing warning signs
* Social engineering information
* Online safety tips
* Simple phishing quiz
* Instant quiz response

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Files

* `index.html` – Main webpage
* `style.css` – Website design
* `script.js` – Quiz functionality

## How to Run

Open `index.html` in a browser to view the website.
